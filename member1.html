BACKGROUND

个人背景

我是一名土生土长的合肥人，从小在逍遥津公园边长大，见证了这座城市从"江淮小邑"成长为科创名城的过程。高中时参加学校信息学社团，第一次写出的"九九乘法表"程序让我迷上了编程；2023 年考入本校计算机科学与技术专业，正式踏上程序员的成长之路。

在校期间担任班级学习委员，参与校级程序设计竞赛并获得二等奖；课余坚持阅读技术书籍，目前在系统学习 Java 与后端开发技术栈，目标是成为能独立交付大型系统的后端工程师。

HOBBIES

兴趣爱好

除了写代码，我还喜欢这些事。

摄影与城市徒步

我喜欢带着相机穿梭于合肥的老街与新区——三河古镇的晨雾、天鹅湖的落日、骆岗中央公园的巨型航站楼，都是我镜头里的常客。摄影让我学会观察细节，也与我的专业"相得益彰"：好的架构师同样需要全局视野。

CAREER PLAN

个人职业技能发展规划

目标岗位：后端开发工程师 → 云计算 / 微服务架构师

大一 · 打基础
语言与数据结构

学透 C 语言、数据结构与算法，通过校赛与 LeetCode 训练编码能力，养成良好编程习惯。

大二 · 定方向

毕业设计 + 秋招

完成高质量毕业设计，冲刺互联网大厂后端岗位，入职后向高并发、云原生架构方向持续深耕。
