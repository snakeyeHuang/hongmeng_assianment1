BACKGROUND

个人背景

我来自皖北平原的阜阳，那里民风淳朴、面食飘香。高中时数学和物理是我的强项，尤其喜欢用"数据说话"的推理过程；2023 年考入本校数据科学与大数据技术专业，如愿以偿地开始和 Python、统计学打交道。

入学后我加入了学校的数据分析社团，参与过校园一卡通消费数据的分析小课题，从清洗数据到画出可视化图表，第一次体会到"让数据讲故事"的乐趣。目前担任社团技术组组长。

HOBBIES

兴趣爱好

球场上的团队配合，和数据项目里的协作其实很像。

篮球 & 运动

我是院篮球队的小前锋，每周固定两次训练。篮球教会我最重要的一件事——"看数据也要看现场"：不能只盯着统计表，还要理解场上真实的对抗与手感，这让我在数据分析时更注重业务背景。

平时也喜欢看电竞比赛、研究选手数据，尝试用 Python 爬取比赛数据做赛后复盘，算是把爱好和专业结合了起来。

CAREER PLAN

个人职业技能发展规划

目标岗位：数据分析师 → 数据科学家 / BI 工程师

大一 · 打基础
Python 与数学

学透 Python 语法、高等数学与线性代数，掌握 NumPy / Pandas 进行数据处理，完成数据可视化入门。

大二 · 学工具
SQL 与统计分析

系统学习 SQL、概率统计与 A/B 测试思想，掌握 Tableau / ECharts 可视化，参加数据分析竞赛。

大三 · 上模型
机器学习与大数据

学习 Scikit-learn、Spark 与常用机器学习算法，完成企业实习或真实业务分析项目。

大四 · 入职场
作品集 + 秋招

沉淀数据分析作品集，冲刺互联网与金融行业数据岗位，向数据科学、大模型应用方向进阶。
